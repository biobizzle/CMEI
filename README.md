# CMEI landing page

A React, Vite, TypeScript and Tailwind landing page for the Creative Media Empowerment Initiative.

```sh
npm install
npm run dev
npm run build
```

The project includes approved leadership portraits. Portfolio entries, testimonial text, sponsor names and contact details are clearly identified placeholders. Replace the externally hosted reference videos with CMEI-owned or licensed footage before publication. Application, contact and sponsorship forms are not connected.
